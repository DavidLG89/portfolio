La **PFO1** consiste en desarrollar una landing page de portafolio personal utilizando **HTML y CSS**, donde presentes tu nombre, perfil, habilidades, contacto y una sección personal. Debe incluir HTML semántico, diseño responsive con Flexbox o Grid, Google Fonts, una transición o animación, imágenes con `alt`, un formulario con `label` y un enlace visible a tu perfil de GitHub.

Además, el proyecto debe publicarse en **Vercel** y contar con un **README.md** que explique brevemente la PFO1, incluya la URL publicada, las decisiones tomadas y la declaración de uso de IA.

# Portfolio personal

Portfolio web personal desarrollado únicamente con HTML y CSS. El proyecto presenta información personal, hobbies, habilidades y datos de contacto en un diseño responsive.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Imágenes públicas de Unsplash
- Íconos de tecnologías desde Devicon

## Uso de inteligencia artificial

Para desarrollar este proyecto utilicé **Codex, un asistente de programación de OpenAI**. Lo usé para recibir ayuda durante la creación y mejora del código HTML y CSS.

La inteligencia artificial fue utilizada para:

- Crear la estructura semántica inicial del portfolio.
- Proponer y escribir estilos responsive con Flexbox y CSS Grid.
- Incorporar accesibilidad básica, como textos alternativos en las imágenes y el uso adecuado de etiquetas semánticas.
- Mejorar la jerarquía tipográfica, los colores, las animaciones y las transiciones.
- Adaptar el diseño a una estética oscura y tecnológica con violeta como color de acento.
- Ordenar el contenido de la sección “Sobre mí” en párrafos legibles.
- Agregar imágenes públicas para los hobbies e íconos para las habilidades.

## Plan utilizado

Se utilizó el **plan gratuito** de la herramienta de inteligencia artificial.

## Experiencia previa con la herramienta

No tenía experiencia previa utilizando Codex ni asistentes de programación. Solamente tenía experiencia usando ChatGPT en formato de chat.

## Revisión y adaptación con criterio propio

Aunque se utilizó inteligencia artificial como apoyo, revisé y adapté el proyecto según mis propias decisiones y necesidades. En particular:

- Reemplacé los datos de ejemplo por mi nombre, correo electrónico y foto de perfil.
- Escribí y adapté el contenido personal de la sección “Sobre mí”.
- Elegí las habilidades que quería mostrar: HTML, CSS, Java, Spring Boot y MySQL.
- Seleccioné los hobbies que me representan: ciclismo, leer y jugar videojuegos.
- Pedí una estética moderna y tecnológica, con fondo oscuro, violeta como acento y elementos visuales sobrios.
- Revisé que la estructura tuviera secciones claras, navegación interna y diseño adaptable para computadoras y dispositivos móviles.
- Se mejoró la presentación del texto separándolo en párrafos reales para facilitar su lectura.
- Se mantuvieron los íconos decorativos sin texto alternativo para no repetir información que ya aparece escrita en cada habilidad.
- Se agregaron animaciones suaves y una opción que reduce el movimiento para respetar las preferencias de accesibilidad del usuario.

La inteligencia artificial fue una herramienta de apoyo; las decisiones sobre el contenido personal, las habilidades, los hobbies y la dirección visual del portfolio fueron adaptadas durante el desarrollo del proyecto.
